# Customer Shopping Behavior Analysis

A data analytics project exploring customer shopping behavior with Python, PostgreSQL, and Power BI. The project cleans and prepares the dataset, loads it into PostgreSQL, answers business questions with SQL, and presents insights in a Power BI dashboard.

## Project files

- `Customer_shopping_behavior.csv` — customer shopping dataset.
- `main.py` — cleans the data, adds analysis fields, and loads it into PostgreSQL.
- `Customer_shoping_behaviour_psql_queries.sql` — SQL queries for customer and product analysis.
- `Customer_shopping_behaviour_dashboard.pbix` — Power BI dashboard.


## Tools used

- Python
- PostgreSQL
- Power BI
- pandas


## Setup

### 1. Create a PostgreSQL database

Create a database named `Customer_shopping_behaviour`, or set a different name using the `PGDATABASE` environment variable.
